# Movie Island

## À propos

Movie Island est un projet personnel full-stack que j’ai conçu et développé dans le cadre de ma montée en compétences en développement web. 
Il s’agit d’une application web dédiée aux passionnés de cinéma, offrant à la fois une bibliothèque de films et des quiz personnalisés générés par intelligence artificielle.

## Caractéristiques

État du projet : En cours

Technologies : Next.js, TypeScript, Tailwind CSS, Node.js, Express, PostgreSQL

Services : Neon (Serveless Postgres), Vercel

IDE : VSCode

OS : Windows
